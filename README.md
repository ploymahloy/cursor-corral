**Lasso the cursors, rule the ranch.**

A browser game where you play a cursor rancher rounding up wild cursor “cows” into a corral.

## Status

The status of this game is still early, BUT it is playable! Navigate to https://cursor-corral.vercel.app/ to play.

## Concept

- You control a rancher cursor with a lasso.
- Loose cursor cows wander the pasture.
- Your job is to corral them inside the fence.
